# Homebrew tap for InfernoSIM

Install the latest stable InfernoSIM release with:

```bash
brew install pranaysparihar/infernosim/infernosim
```

The formula builds the tagged source locally. It is updated from the latest
public [InfernoSIM release](https://github.com/pranaysparihar/InfernoSIM/releases)
by a repository-scoped GitHub Actions workflow, so no cross-repository personal
access token is required.
